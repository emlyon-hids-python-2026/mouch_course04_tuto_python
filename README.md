# mouch_course04_tuto_python

A Python project for the emlyon business school Python programming course.

## Installation

```bash
git clone https://github.com/emlyon-hids-python-2026/mouch_course04_tuto_python.git
cd mouch_course04_tuto_python
uv sync
```

## Usage

```bash
uv run scripts/demo.py
```

## Project structure

- `data/`: datasets (not tracked by git)
- `notebooks/`: Jupyter notebooks
- `scripts/`: Python scripts
- `src/`: Python package
